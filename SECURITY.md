# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by **one** of the following methods:

1. **Open a GitHub issue** — use the issue title to request private contact details (do **not** include vulnerability details in the issue body).
2. **Email** the maintainers directly at marco@example.com.

We will acknowledge receipt within **48 hours** and work on a fix as soon as possible.

## Supported Versions

Only the **latest published version** on npm receives security updates. Please ensure you are using the most recent release before reporting a vulnerability.
